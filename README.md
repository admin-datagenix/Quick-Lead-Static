# QuickLeads Marketing Site (Static)

Premium, responsive marketing homepage for **QuickLeads by DatagenixAI** — built with React, Vite, Tailwind CSS v4, Framer Motion, and Lucide icons.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Links

- Live product sign-in: https://quick-lead-jet.vercel.app/
- CTAs on this site point to that app URL; pricing tiers use configurable limits (contact for paid plans).
